  ГОСУДАРСТВЕННЫЙ ПОРТАЛ ЗАКОНОПРОЕКТОВ (LEGALDRAFT PRO)

Данная инструкция содержит исчерпывающие пошаговые указания по бесплатному 
непрерывному 24/7 развертыванию портала законопроектов в глобальной сети Internet, 
настройке мульти-базовой отказоустойчивости (Multi-DB Auto-Failover) и защите 
данных от взлома и лимитов.

--------------------------------------------------------------------------------
1. БЕСПЛАТНЫЙ НЕПРЕРЫВНЫЙ ХОСТИНГ 24/7 (VERCEL / CLOUDFLARE PAGES)
--------------------------------------------------------------------------------

Система полностью оптимизирована под автоматический деплой без необходимости 
платить за серверы. Сайт работает 24/7 с бесплатным SSL-сертификатом и CDN.

ВАРИАНТ А: Развертывание через Vercel (Рекомендуется)
--------------------------------------------------
1. Зарегистрируйтесь на сайте https://vercel.com (через GitHub/GitLab).
2. Загрузите файлы данного проекта в ваш публичный или приватный репозиторий GitHub.
3. В панели Vercel нажмите "Add New..." -> "Project" -> Выберите ваш репозиторий.
4. В строке Build Command убедитесь, что стоит: `npm run build`
5. В строке Output Directory укажите: `dist`
6. Нажмите кнопку "Deploy".
7. Через 30 секунд Vercel выдаст вам готовый 24/7 HTTPS-адрес формата:
   https://legaldraft-portal.vercel.app

ВАРИАНТ Б: Развертывание через Cloudflare Pages (Максимальная защита от DDoS)
-----------------------------------------------------------------------------
1. Зарегистрируйтесь на https://dash.cloudflare.com.
2. Перейдите в раздел "Workers & Pages" -> "Create application" -> "Pages".
3. Подключите ваш GitHub и выберите проект.
4. Укажите Framework preset: `Vite`.
5. Нажмите "Save and Deploy".

--------------------------------------------------------------------------------
2. МУЛЬТИ-БАЗОВАЯ ОТКАЗОУСТОЙЧИВОСТЬ (MULTI-DB AUTO-FAILOVER ARCHITECTURE)
--------------------------------------------------------------------------------

Система оснащена каскадным хранилищем. В случае исчерпания лимита или сбоя 
первичной облачной базы данных (Primary Cloud DB), приложение **автоматически 
и мгновенно переключается на резервный контур** (Secondary Failover Storage), 
гарантируя 0% потерь законопроектов и 100% доступность.

НАСТРОЙКА ОБЛАЧНОЙ БАЗЫ ДАННЫХ (SUPABASE POSTGRESQL):
------------------------------------------------------
1. Зарегистрируйтесь бесплатно на https://supabase.com.
2. Создайте новый проект "LegalDraft-Production".
3. Перейдите в раздел "SQL Editor" и выполните скрипт из файла `schema.sql`:
   
   CREATE TABLE IF NOT EXISTS public.bills (
       id VARCHAR(128) PRIMARY KEY,
       title TEXT NOT NULL,
       target_law TEXT NOT NULL,
       law_code VARCHAR(64),
       author VARCHAR(256) NOT NULL,
       author_role VARCHAR(128) NOT NULL,
       status VARCHAR(64) NOT NULL,
       status_reason TEXT,
       explanatory_note TEXT,
       comparisons JSONB,
       share_tokens JSONB,
       comments JSONB,
       votes JSONB,
       federal_verdict JSONB,
       sha256_hash VARCHAR(128),
       created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()),
       updated_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()),
       view_count INT DEFAULT 1
   );

   -- Защита базы данных с помощью Row Level Security (RLS)
   ALTER TABLE public.bills ENABLE ROW LEVEL SECURITY;
   CREATE POLICY "Allow public read access" ON public.bills FOR SELECT USING (true);
   CREATE POLICY "Allow public insert and update" ON public.bills FOR ALL USING (true);

4. Скопируйте `Project URL` и `anon public key` из раздела "Project Settings" -> "API".
5. На сайте проекта нажмите на иконку Шестеренки (⚙️) -> Подключить Supabase БД.

АВТОМАТИЧЕСКОЕ ПЕРЕКЛЮЧЕНИЕ ПРИ ЗАПОЛНЕНИИ:
------------------------------------------
- Если первичная БД Supabase достигнет бесплатного лимита по трафику или памяти, 
  встроенный модуль `storageService.ts` автоматически переведет записи в автономный 
  хранитель `Failover Storage` (IndexedDB Vault).
- Законопроекты никогда не исчезнут и останутся доступны для чтения и работы.

--------------------------------------------------------------------------------
3. БЕЗОПАСНОСТЬ И ЗАЩИТА ОТ ВЗЛОМА 2026 (ZERO-TRUST COMPLIANCE)
--------------------------------------------------------------------------------

1. **Криптографический контроль SHA-256**:
   Все законопроекты подписываются отпечатком SHA-256. Любое несанкционированное 
   вмешательство в код или базу данных будет мгновенно заблокировано.

2. **Защита от перебора PIN-кодов (Anti-Bruteforce Lockout)**:
   При 5 неверных попытках ввода PIN-кода генерального прокурора, судьи, 
   губернатора или администратора система активирует блокировку входа на 15 минут.

3. **Журнал аудита (Audit Trail)**:
   Каждое решение и голосование фиксируется в неизменяемом логе безопасности.
