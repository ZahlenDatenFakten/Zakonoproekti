================================================================================
  ПОЛНАЯ ИНСТРУКЦИЯ ПО РАЗВЕРТЫВАНИЮ НА VPS U1HOST.COM (ДЛЯ ВТОРОГО САЙТА)
  ТАРИФ: DE-5950X-2 (2 vCPU / 4 ГБ ОЗУ / 60 ГБ SSD)
================================================================================

Данная пошаговая инструкция написана простым языком («для чайников») и содержит 
все необходимые команды, чтобы развернуть данный проект на вашем сервере VPS от 
u1host.com в качестве ВТОРОГО сайта (на отдельном домене или поддомене) 
без конфликтов с первым сайтом и с поддержкой базы данных и SSL (HTTPS).

--------------------------------------------------------------------------------
ШАГ 1: ПОДКЛЮЧЕНИЕ К ВАШЕМУ VPS СЕРВЕРУ ПО SSH
--------------------------------------------------------------------------------

1. Откройте командную строку Windows (PowerShell или CMD) или программу PuTTY.
2. Введите команду для подключения (замените `123.45.67.89` на IP вашего VPS):
   
   ssh root@123.45.67.89

3. Сервер запросит пароль root (он приходит в письме от u1host при покупке VPS).
   *Примечание: При вводе пароля символы в консоли не отображаются — это нормально.*

--------------------------------------------------------------------------------
ШАГ 2: УСТАНОВКА НЕОБХОДИМЫХ ПРОГРАММ НА СЕРВЕР (Node.js, Git, Nginx, PM2)
--------------------------------------------------------------------------------

Выполняйте команды по очереди (просто скопируйте и вставьте в консоль):

1. Обновление пакетов сервера:
   sudo apt update && sudo apt upgrade -y

2. Установка Git и Nginx (веб-сервер):
   sudo apt install -y git nginx curl

3. Установка Node.js (версии 20 LTS):
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt install -y nodejs

4. Установка PM2 (менеджер фонового авто-запуска 24/7):
   sudo npm install -g pm2

--------------------------------------------------------------------------------
ШАГ 3: УСТАНОВКА И НАСТРОЙКА БАЗЫ ДАННЫХ POSTGRESQL (ДЛЯ ПРОЕКТА)
--------------------------------------------------------------------------------

1. Установите PostgreSQL на VPS:
   sudo apt install -y postgresql postgresql-contrib

2. Войдите в консоль управления PostgreSQL:
   sudo -u postgres psql

3. Выполните следующие SQL-команды в консоли psql (замените `my_password` на ваш пароль):

   CREATE DATABASE legaldraft_db;
   CREATE USER legaldraft_user WITH PASSWORD 'my_password';
   GRANT ALL PRIVILEGES ON DATABASE legaldraft_db TO legaldraft_user;
   \c legaldraft_db;

4. Скопируйте и вставьте таблицы из schema.sql:

   CREATE TABLE IF NOT EXISTS public.bills (
       id VARCHAR(128) PRIMARY KEY,
       title TEXT NOT NULL,
       target_law TEXT NOT NULL,
       law_code VARCHAR(64),
       author VARCHAR(256) NOT NULL,
       author_role VARCHAR(128) NOT NULL,
       status VARCHAR(64) NOT NULL,
       status_reason TEXT,
       explanatory_note TEXT,
       comparisons JSONB,
       share_tokens JSONB,
       comments JSONB,
       votes JSONB,
       federal_verdict JSONB,
       sha256_hash VARCHAR(128),
       created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()),
       updated_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()),
       view_count INT DEFAULT 1
   );
   \q

--------------------------------------------------------------------------------
ШАГ 4: СКАЧИВАНИЕ ПРОЕКТА С GITHUB И СБОРКА
--------------------------------------------------------------------------------

1. Перейдите в папку веб-сайтов:
   cd /var/www

2. Клонируйте ваш репозиторий с GitHub:
   git clone https://github.com/ZahlenDatenFakten/Zakonoproekti.git site2_zakon

3. Перейдите в папку проекта:
   cd site2_zakon

4. Установите зависимости:
   npm install

5. Скомпилируйте проект:
   npm run build

--------------------------------------------------------------------------------
ШАГ 5: НАСТРОЙКА NGINX ДЛЯ ВТОРОГО САЙТА (ЧТОБЫ НЕ МЕШАТЬ ПЕРВОМУ)
--------------------------------------------------------------------------------

1. Создайте конфигурационный файл Nginx для второго сайта:
   sudo nano /etc/nginx/sites-available/site2_zakon

2. Вставьте в открывшийся редактор следующий текст (замените `zakon.yourdomain.com` на ваш второй домен или поддомен):

server {
    listen 80;
    server_name zakon.yourdomain.com; # ВАШ ВТОРОЙ ДОМЕН ИЛИ ПОДДОМЕН

    root /var/www/site2_zakon/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # Защита от частых запросов
    location ~ /\. {
        deny all;
    }
}

3. Сохраните файл: нажмите `Ctrl + O`, затем `Enter`. Закройте nano: `Ctrl + X`.

4. Активируйте второй сайт в Nginx:
   sudo ln -s /etc/nginx/sites-available/site2_zakon /etc/nginx/sites-enabled/

5. Проверьте правильность конфигурации Nginx:
   sudo nginx -t

6. Перезапустите Nginx:
   sudo systemctl restart nginx

--------------------------------------------------------------------------------
ШАГ 6: БЕСПЛАТНЫЙ SSL СЕРТИФИКАТ (HTTPS — ЗАМОЧЕК В БРАУЗЕРЕ)
--------------------------------------------------------------------------------

1. Установите Certbot:
   sudo apt install -y certbot python3-certbot-nginx

2. Выпустите бесплатный SSL-сертификат для второго сайта:
   sudo certbot --nginx -d zakon.yourdomain.com

   *Certbot сам настроит HTTPS и автоматическое продление!*

--------------------------------------------------------------------------------
ШАГ 7: ГОТОВО! ПРОВЕРКА РАБОТОСПОСОБНОСТИ
--------------------------------------------------------------------------------

Теперь ваш Второй сайт работает непрерывно 24/7 по адресу:
https://zakon.yourdomain.com

-------------------------------------------------------------------

   cd /var/www/site2_zakon
   git pull origin main

Поздравляем! Ваш портал законопроектов работает на тарифе DE-5950X-2 с высшей производительностью!
